# Health Service Mobile App

A simple React Native Expo app for a health service platform.

## Features
- Patient dashboard
- Doctor directory
- Appointment tracking
- Health summary cards
- Profile and care overview
- Bottom navigation UI

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npx expo start
   ```

## Available scripts
- `npm start`
- `npm run android`
- `npm run ios`
- `npm run web`

## Stack
- React Native
- Expo
- TypeScript
